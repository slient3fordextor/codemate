# 开源策略与成本

## 1. 开源定位

CodeMate 是开源 Agent 项目。MVP 不设计定价、不提供付费套餐，也不提供官方公共 Demo。

项目优先本地运行。用户自行选择本地模型或第三方模型 API。

| 项目 | 策略 |
| --- | --- |
| 代码仓库 | 公开核心代码、文档和示例配置 |
| 许可证 | 待评审：MIT、Apache-2.0 或 AGPL-3.0 |
| 使用方式 | 仅本地运行，用户配置本地模型或第三方 API Key |
| 社区协作 | 通过 Issue、Discussion、PR 收集反馈和贡献 |
| 插件生态 | 后续支持工具、模型适配器和工作流 |

## 2. 不提供公共 Demo

MVP 不提供官方公共 Demo。

原因：

- 避免为匿名用户承担模型 API 成本。
- 避免在官方服务器上托管或处理用户项目代码。
- 保持清晰的信任边界：用户代码默认留在本地。
- 降低基础设施、滥用防护和合规负担。

## 3. 代码托管边界

MVP 阶段 CodeMate 不托管用户项目代码。

这意味着：

- 用户不需要把仓库上传到 CodeMate 服务器。
- CodeMate 不在官方数据库中保存用户源码。
- 项目文件读取和索引在用户本地环境完成。
- 只有用户配置第三方模型后，才会发起第三方模型调用。
- 发送选中代码或文件片段到第三方模型 API 前，应向用户提示。

## 4. 成本归属

开源不代表所有运行方式都完全免费。CodeMate 本身不收软件费用，但用户可能需要承担模型 API 或本地硬件资源成本。

| 成本项 | 是否必然产生 | 说明 |
| --- | --- | --- |
| 第三方模型 API | 取决于配置 | OpenAI、Anthropic 和兼容 API 通常按量计费 |
| 本地模型 | 取决于配置 | 不产生 API 费用，但消耗本地 CPU/GPU/内存 |
| 向量索引 | 可能产生 | 本地存储成本低，云向量数据库会产生费用 |
| 代码执行沙箱 | 可能产生 | 本地执行消耗机器资源 |
| 网络访问 | 可能产生 | 第三方 API 需要外部网络，本地模型可离线运行 |

## 5. 支持的运行模式

### 5.1 本地模型模式

用户在本机运行开源模型。CodeMate 不产生 API 费用，但质量和速度取决于用户硬件和所选模型。

### 5.2 第三方 API 模式

用户配置自己的 OpenAI、Anthropic 或兼容模型 API Key。模型调用费用由用户自己的服务商账号承担。

## 6. 产品策略

- MVP 不提供官方公共 Demo。
- 不承担用户模型 API 费用。
- 不托管用户项目代码。
- 不隐藏模型用量。
- 对包含代码上下文的第三方模型调用给出清晰提示。
