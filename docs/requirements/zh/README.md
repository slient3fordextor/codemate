# CodeMate 需求文档

版本：v1.2  
最后更新：2026-07-03  
状态：评审初稿

CodeMate 是一个开源本地编程 Agent。项目不提供公共 Demo，不托管用户项目代码，也不对软件本身收费。用户在本地运行，并自行选择本地模型或第三方大模型 API。

## 当前决策

- MVP 默认本地运行。
- 不提供官方公共 Demo。
- 不托管用户项目代码。
- MVP 不设计定价或付费套餐。
- 模型方式支持本地模型或用户自带第三方 API Key。
- 后端推荐 FastAPI。
- 前端 CLI 对话页第一版推荐采用“类 ChatGPT 页面 + 命令卡片”，后续演进为完整 Web 工作台。
