# 产品需求

## 1. 产品概述

### 1.1 产品定位

CodeMate 是面向开发者的 AI 编程助手。它通过对话式工作流帮助用户理解项目代码、生成代码、修改代码、解释错误并完成编码任务。

MVP 阶段聚焦本地运行、项目上下文理解和轻量 Web 工作台。

### 1.2 核心价值

- 提升效率：减少重复编码、样板代码和文档编写工作。
- 提升质量：基于项目上下文生成更安全的代码建议和测试。
- 辅助学习：解释代码逻辑、错误原因和最佳实践。
- 保持一致性：尽量遵循现有项目结构和代码风格。

### 1.3 目标用户

| 用户类型 | 特征 | 核心需求 |
| --- | --- | --- |
| 独立开发者 | 全栈开发，时间紧张 | 生成样板代码、定位问题、补齐测试 |
| 团队 Leader | 关注质量和交付效率 | 代码审查辅助、重构建议、规范一致性 |
| 初级工程师 | 处于学习和经验积累阶段 | 代码解释、错误分析、最佳实践指导 |
| DevOps 工程师 | 处理脚本和自动化配置 | 生成脚本、解释配置、排查 CI/CD 问题 |

## 2. MVP 范围

### 2.1 MVP 目标

MVP 用于验证 CodeMate 是否能在真实本地项目中稳定辅助编码。

- 支持基于项目文件的对话问答。
- 支持针对一个或少量文件的代码生成、解释和小范围修改。
- 提供基础 Web 工作台。
- 跟踪任务状态、错误和基础使用指标。

### 2.2 非目标

以下内容不进入 MVP：

- 同时交付所有 IDE 插件。
- 跨项目长期记忆和个性化学习。
- 企业级私有化部署包。
- 大规模远程执行集群。
- 完整 SOC2/GDPR 审计体系。
- 模型训练或微调平台。
- 官方公共 Demo。

### 2.3 MVP 成功指标

| 指标 | 目标值 | 统计口径 |
| --- | --- | --- |
| 7 日留存 | >= 30% | 完成一次编码任务的注册用户 |
| 代码建议接受率 | >= 40% | 用户应用或复制生成代码 |
| 首 Token 延迟 | P95 <= 3s | 从提交请求到首次流式输出 |
| 任务成功率 | >= 95% | 排除用户取消和模型拒答后的正常完成任务 |
| 用户满意度 | >= 4.0/5 | 任务后评分 |

## 3. 功能需求

### 3.1 P0 需求

#### F1 对话式编程

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| F1.1 | 支持多轮对话 | 单个会话至少保留最近 10 轮上下文 |
| F1.2 | 支持代码解释 | 能解释用户选择的文件或代码片段 |
| F1.3 | 支持追问修改 | 用户可以基于上一次回答继续要求调整 |
| F1.4 | 支持中英文输入 | 可处理中文、英文和中英文混合问题 |
| F1.5 | 支持流式输出 | 回答内容逐步展示 |

#### F2 代码生成

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| F2.1 | 根据自然语言生成代码 | 输出代码块和必要说明 |
| F2.2 | 支持核心语言 | MVP 支持 Python、JavaScript、TypeScript |
| F2.3 | 生成测试 | 对明确指定的函数或模块生成测试示例 |
| F2.4 | 生成注释和文档 | 支持函数、类和 API 文档生成 |

#### F3 代码修改

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| F3.1 | 修改指定文件或片段 | 输出修改内容和修改原因 |
| F3.2 | 修复常见错误 | 对语法错误、异常堆栈、测试失败给出修复建议 |
| F3.3 | 小范围重构 | 支持提取函数、简化逻辑、改善命名 |
| F3.4 | 变更预览 | 应用修改前展示修改摘要 |

#### F4 项目上下文

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| F4.1 | 读取文件树 | 展示并使用项目目录结构 |
| F4.2 | 读取当前文件 | 回答能引用当前文件上下文 |
| F4.3 | 检索相关文件 | 根据问题检索少量相关文件 |
| F4.4 | 上下文裁剪 | 上下文过大时优先保留当前文件和相关片段 |

#### F5 基础安全与治理

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| F5.1 | 敏感信息提醒 | 识别疑似 API Key、密码并请求用户确认 |
| F5.2 | 请求限流 | 支持基础用户级限流 |
| F5.3 | 操作日志 | 记录请求、模型、耗时和错误状态 |
| F5.4 | 失败降级 | 模型或服务失败时返回清晰错误 |

## 4. 产品体验

### 4.1 Web 工作台

- 左侧：项目文件树。
- 中间：代码查看和编辑区域。
- 右侧：AI 对话面板。
- 底部：任务状态、错误信息和日志摘要。

### 4.2 核心流程

1. 用户打开本地项目。
2. 系统读取文件树和当前文件。
3. 用户提问或选择代码。
4. CodeMate 检索相关上下文并生成回答。
5. 用户查看代码建议。
6. 用户复制或应用修改。
7. 系统记录反馈和任务状态。

### 4.3 交互反馈

| 场景 | 反馈方式 |
| --- | --- |
| 开始生成 | 显示加载状态和取消按钮 |
| 生成中 | 流式输出内容 |
| 生成完成 | 显示复制、应用、重新生成操作 |
| 出错 | 展示清晰原因和可执行建议 |
| 上下文不足 | 提示用户选择文件或补充信息 |

## 5. 非功能需求

### 5.1 性能

| 指标 | MVP 目标 | 说明 |
| --- | --- | --- |
| 首 Token 延迟 | P95 <= 3s | 不包含用户网络问题 |
| 完整响应时间 | P95 <= 30s | 长任务需要展示进度 |
| 并发用户 | 100 | MVP 验证规模 |
| 任务成功率 | >= 95% | 服务端正常返回 |
| 可用性 | >= 99.5% | MVP 目标 |

### 5.2 安全

| 编号 | 要求 |
| --- | --- |
| S1 | 远程调用使用 HTTPS |
| S2 | 本地项目访问限定在用户配置的工作区路径内 |
| S3 | 日志不记录明文密钥、密码和完整源码 |
| S4 | 向第三方模型发送内容前检测敏感信息 |
| S5 | 用户可删除会话和项目索引 |

### 5.3 可靠性

| 编号 | 要求 |
| --- | --- |
| R1 | 模型调用失败最多重试 2 次 |
| R2 | 第三方模型不可用时返回清晰错误 |
| R3 | 任务状态可追踪 |
| R4 | 关键配置支持回滚 |
| R5 | 启用持久化时备份本地元数据 |

## 6. 监控指标

| 指标 | 说明 |
| --- | --- |
| DAU | 日活用户数 |
| 激活率 | 新用户首日完成一次有效编码任务的比例 |
| 代码建议接受率 | 复制或应用建议的比例 |
| 任务成功率 | 正常完成任务的比例 |
| 首 Token 延迟 | 模型响应速度 |
| 单次任务成本 | 模型调用、检索和执行资源消耗 |
| 用户满意度 | 任务后评分 |

## 7. 告警

| 告警 | 条件 | 等级 |
| --- | --- | --- |
| API 错误率过高 | 5 分钟错误率 > 5% | P0 |
| 模型调用失败 | 5 分钟失败率 > 10% | P0 |
| 延迟过高 | 首 Token 延迟 P95 > 5s 持续 10 分钟 | P1 |
| 配额问题 | 用户配置的第三方 API 配额不足或调用失败 | P2 |
