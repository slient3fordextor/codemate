# 已实现边界与未落地流程

本页用于区分“代码可运行”与“需求/设计已提出”。2026-10-21 已按当前未提交工作区校准；实测范围与后续执行顺序见 [当前主线与未完成清单](../engineering/zh/18-当前主线与未完成清单-2026-10-21.md)。已有实现不等于发布验收完成。

## 已完成的主流程

- 本地 Web 对话页面、完整历史恢复、会话搜索/分页/重命名/归档/删除/导出和 SSE 增量渲染；
- 模型配置查询与写回 `.env`；
- mock、OpenAI 兼容和 Anthropic 的流式模型适配；
- 单条消息模式的 SQLite L1/L2/L3 分层记忆；
- Token 整体预算、确定性记忆冲突检测、分块智能压缩和记忆管理 API；
- Python、JavaScript、TypeScript 的规则式语言和项目类型提示；
- 健康检查、请求 ID、访问日志和统一 HTTP 错误响应。
- `codemate`/`codemate run` Agent：`readonly/confirm/agent` 策略、受限读取/Git、diff 提案与审批写入、Bubblewrap 验证、worktree 隔离、SQLite checkpoint 及显式 deliver/discard；
- API 默认仅允许本机访问，可显式启用 Bearer Token 远程访问，并有进程内固定窗口限流；
- 模型网络适配器在尚未产生流式输出时，对超时、传输错误、429 和 5xx 进行有限重试；
- 模型配置以原子替换写入实际加载的项目根 `.env`，并拒绝覆盖由进程环境变量管理的配置。
- 可写 CLI 的任务生命周期跨进程互斥、交付/回退串行，以及新目录文本/二进制/空文件交付；
- 同源本机桌面 WebSocket、Linux X11 的跨 worker 互斥与逐动作审批，停止/断连取消；
- wheel 的静态资源打包、本地与 CI 共用门禁、内部文档文件链接与干净安装烟测。

## 尚未接入运行链路

| 主题 | 当前状态 |
| --- | --- |
| 文件树、文件读取、相关文件检索 | 只读 CLI 与 Web 已有受限目录/文件访问，Web 可附加正文、选区与 tracked diff；尚无语义检索、相关文件排序或并行读取 Scheduler。 |
| 当前文件内容 | `current_file` 本身仍只做路径/语言判断；正文通过显式 `context` 附件发送，用户可预览与移除。 |
| 自动代码修改与变更预览 | 普通聊天仍只展示答案；独立 Web 编码工作台已接入任务、diff 审批、worktree 写入及显式交付/回退，浏览器完整流程待验收。 |
| 命令执行与验证 | Web 编码任务已通过共享任务服务运行 Bubblewrap 白名单命令，另有 Python 验证模板；不执行任意聊天代码块。 |
| 通用任务状态持久化 | CLI/Web 编码任务共享 TaskRecord、图事件、运行与审批记录；聊天完整历史仍使用独立数据库，不等同于编码任务。 |
| 记忆管理与多机共享 | 已有偏好/冲突查询、删除 API 与管理面板；尚无偏好编辑/恢复、数据库加密；SQLite 只支持单机多进程。 |
| 重试 | OpenAI 兼容与 Anthropic 适配器只在首个流式块前有限重试；命令不自动重试，未知中断结果恢复后要求审批。 |
| 限流和敏感内容检测 | API 支持进程内固定窗口或共享 SQLite 限流；多机统一边界由网关负责。敏感检测已用于记忆落盘和工具路径/内容过滤。 |
| tree-sitter、LSP、按字节/文件数裁剪 | 多语言配置项存在，L1 实现未调用这些能力。 |
| SSE 取消 | 停止与异常断流保留部分文本，慢上游轮询断连并关闭，历史记录终态，模型完成不等同于应用保存成功；不是可写任务 checkpoint 恢复或上游计费取消保证。 |
| 写入、验证与隔离 | 可写任务使用独立 Git worktree、审批补丁和无网络 Bubblewrap 验证；源工作区仅在显式 `deliver` 且无重叠冲突时更新。 |
| Agent 恢复 | 可写 CLI/Web 任务已接入 TaskBudget、消息 checkpoint 与跨运行累计预算，旧审批不复用；普通只读 CLI 仍直接使用 Runner，不支持任意执行中动作的精确恢复。 |
| 工具协议 | 已适配 OpenAI/Anthropic 原生 tool-call 事件并汇聚分块参数；保留严格 JSON 决策兼容路径，两种路径均校验工具和参数。 |
| 桌面控制 | X11 同一用户/显示服务器的跨 worker 锁与逐动作审批已实现；仅固定 xdotool 工具，无截图理解，不能将命令成功当作应用状态验证；Wayland/远程 DISPLAY 不支持。 |

## 维护原则

新增能力时应先更新对应流程文档：说明入口、前置条件、成功路径、失败与取消分支、持久化边界，以及是否会向模型发送文件内容。这样流程文档可以继续作为代码审查和联调的依据。
