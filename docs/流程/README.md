## 总体链路

```text
浏览器页面
  -> POST /api/v1/chat/completions
  -> ChatService 组装消息、记忆、代码上下文和操作模式
  -> 模型适配器调用 provider 的流接口
  -> 标准 ModelChunk
  -> SSE 事件
  -> 浏览器逐段渲染回答并保存 session_id
```

模型配置使用独立链路：浏览器调用 `GET/PUT /api/v1/model-config`，服务端读取或更新工作区根目录的 `.env`，随后清除 `get_settings()` 缓存，使后续对话请求加载新配置。

## 阅读约定

- “当前行为”以 `app/` 和 `app/static/` 代码为准。
- “尚未实现”表示需求或配置存在，但当前请求链路没有对应执行代码。
- `current_file` 仅用于构造模型上下文，不会把文件正文读入请求；`selected_text` 才会被直接附加到上下文中。
