## 推荐落地顺序

1. 先阅读 `00`，确认脚手架中每个架构分层的用途。
2. 再完成 `01` 到 `04`，得到可启动、可检查、可调试的 FastAPI 服务。
3. 继续完成 `05`，优先建立本地文件访问安全边界。
4. 接着完成 `06` 和 `07`，让对话接口可以通过 mock 模型流式输出。
5. 完成 `08` 到 `11`，补齐状态持久化、测试、配置和 L1 会话记忆。
6. 再阅读 `12` 到 `14`，规划多语言支持、上下文预算和受控命令执行。

## 当前状态判断

当前仓库已有可运行的 FastAPI、流式模型适配、模型配置、多语言上下文和 SQLite 分层记忆。记忆侧 Token 预算、冲突治理和确定性智能压缩已落地；命令执行沙箱、语义索引、多机存储和管理 UI 仍属于后续能力。
