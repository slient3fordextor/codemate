# 项目文件访问与安全边界

## 目标

为本地项目文件读取建立安全边界，确保 CodeMate 只能访问用户配置的工作区范围。

## 核心原则

所有文件访问必须通过统一适配器，例如：

```text
app/adapters/filesystem.py
```

API 层和服务层不应直接调用 `open()` 读取任意路径。

## 工作区限制

必须校验：

- 请求路径解析后位于 `WORKSPACE_ROOT` 内。
- 禁止 `../` 路径穿越。
- 禁止符号链接逃逸。
- 默认不读取 `.git`、`.env`、私钥和密钥文件。
- 限制单文件大小和总上下文大小。

## 建议接口

```text
GET /api/v1/projects/tree
GET /api/v1/projects/files?path=...
```

`tree` 接口返回目录结构，不返回文件内容。

`files` 接口读取文件内容前执行路径校验、大小校验和敏感信息检测。

## 敏感信息检测

MVP 可先使用规则检测：

- `api_key`
- `secret`
- `password`
- `token`
- 私钥块。
- 常见云服务密钥格式。

检测到疑似敏感信息时，不应直接发送给第三方模型，应返回需要用户确认的状态。

## 验收标准

- 任何路径穿越请求都会被拒绝。
- 符号链接无法逃出工作区。
- `.env` 和私钥文件默认不可读。
- 文件读取有大小限制。
- 相关行为有单元测试。

## 风险点

- 本地 Agent 的最大信任风险是误读或误发用户敏感文件。
- 如果文件访问逻辑分散，后续很难补齐统一审计和脱敏。
