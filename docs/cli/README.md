# CodeMate Agent CLI

本目录定义 CodeMate Agent CLI 的产品方向和后续运行流程。

CLI 是 CodeMate 面向本地开发工作的主入口：用户在一个受控工作区中以自然语言发起任务，代理通过读取项目、提出或执行受授权的修改、运行验证命令来完成任务。Web 页面可以继续作为同一 Agent 能力的可视化客户端，但不应再作为能力设计的前提。
